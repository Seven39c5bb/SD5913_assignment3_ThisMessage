## 这条消息怎么回？ / This Message

一个关于失约、雨夜赴约与告别的中文命令行互动故事。为 SD5913 Assignment 3: An interactive experience 制作。

## 想法与目标用户

你忘记了与朋友林予的书店之约。对方发来一句「你是不是忘了今天的约定？」你需要收拾出门、穿过雨中的城市、赶上分享会的尾声，听听林予今晚特别想见你的原因。也可以提前说明变化，在活动结束后远程交流。

作品面向喜欢日常题材互动故事的中文读者。新版有四幕、33 个对话与行动节点；单次完整游玩需要做 11–19 次选择，阅读时间因人而异。回复、携带物品和行动一起影响剧情。没有好感分数、标准答案、实时倒计时或真实消息发送。

## 运行

需要 Python 3.10 或更新版本，推荐 Python 3.13；没有第三方 Python 依赖，不需要账号、API、网络服务、麦克风或素材下载。首次使用 uv 安装 Python 时需要网络，环境准备完成后游戏可以离线运行。

先在终端进入下载或克隆后的项目文件夹，也就是包含本 README 和 pyproject.toml 的文件夹，然后运行：

```powershell
uv python install 3.13
uv sync --python 3.13 --locked
uv run --locked python main.py
```

如已安装兼容的 Python，也可以直接运行：

```powershell
python main.py
```

自动演示与纯文本模式：

```powershell
uv run --locked python main.py --demo --plain
uv run --locked python main.py --plain
uv run --locked python main.py --no-art
```

没有安装 uv 时，可以先使用上面的 Python 命令。uv 安装说明见 Astral 官方文档：https://docs.astral.sh/uv/getting-started/installation/

Windows 请使用能显示中文的等宽终端字体，建议窗口至少 60 列。程序使用 UTF-8 输入输出，在兼容终端中自动使用颜色；管道输出和 --plain 模式不含颜色控制符。--plain 保留符号画面；--no-art 隐藏画面，适合紧凑显示或屏幕阅读器。窄窗口放不下整幅画时只显示场景名称，避免把图案折行。旧终端出现方框时，请切换到支持中文的字体。

## 怎么玩

| 输入 | 效果 |
| --- | --- |
| 1、2、3 | 选择当前编号对应的回复或行动；选项随状态变化 |
| b 或 /back | 撤回上一条选择；后续分支从记录移除 |
| r 或 /restart | 清空当前记录，从头开始 |
| h 或 /history | 查看当前分支的剧情、对话与选择记录 |
| i 或 /inventory | 查看物品以及已经发生的关键决定 |
| ? 或 /help | 显示帮助和当前选项 |
| q 或 /quit | 退出 |

也支持中文命令「返回」「重玩」「记录」「物品」「帮助」「退出」及全角数字。输入选项后必须按回车；不能自由输入对白。物品会在相关场景自动发挥作用，不需要输入装备或使用命令。

空输入、无效编号和重复数字（例如 11）都会得到解释，不会推进剧情。第一幕返回会提示已经在起点。结局处仍可查看记录、返回或重玩。Ctrl+C 和输入结束会正常退出，不显示报错栈。

## 主要交互

选择回复或行动 → 保存本次决定和获得的物品 → 切换故事节点 → 显示符号画面、旁白、朋友的反应及当前可用选项。

四幕分别是「未读消息」「雨中的城市」「书店的最后一排」「散场之后」。提前说明变化的远程路线会跳过书店内的场景；幕标显示当前所处章节，不是完成率。

14 幅原创 ASCII 场景覆盖手机、房间、书本、背包、城市、地铁、桥、公交、雨街、书店、分享会、地图、咖啡与长椅。

不同决定有后续作用：雨伞让你干燥地走过街口；充电宝让你能在屋檐下打电话；旧手册提供额外的见面话题和路线；冒雨赶路可能让手册淋湿，出现不同的对白和选择；路上是否报位置，以及最初是否含糊承诺，会在之后的回应中体现。

有五种结局主题，其中「把话听完的夜晚」分为见面和远程两种呈现，合计六个结局节点。结局不会显示好坏评分。探索特定物品组合还可以走到河边，完成手册的最后一页。

story.py 保存对白、选项、条件与结局，art.py 保存纯文本画面。main.py 中 Session.available_choices() 根据历史形成的状态筛选选项；Session.choose() 将屏幕编号映射回故事里的实际选项，再保存选择、切换节点。Session.flags 从历史重建物品与决定，因此 Session.back() 返回时能一起恢复当时的状态，不会把后面拿到的东西带回前面。

## 已知限制

- 剧情与回复预先编写，没有自然语言理解或运行时 AI。
- 只提供中文内容和同一晚的故事；虚构角色的回应不应视为现实沟通的预测。
- 不保存存档；退出后重新开始。返回是体验探索功能，不代表真实消息能撤回。
- 没有防连发计时器：11 会被拒绝，但分别输入两次 1 并各按一次回车会处理两次选择。
- 已收到「流程太短、缺少趣味、希望有符号画面」的测试反馈并据此迭代；新版复测和参与者信息仍需补充，见 PROCESS.md。
